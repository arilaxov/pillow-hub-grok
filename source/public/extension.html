install

Four steps. Once.

  1. 1

    Turn on CEP debug mode

    Once. Paste into Terminal — or run enable-debug/Enable-CEP-Debug-Mac.command from the archive (right-click → Open).

    defaults write com.adobe.CSXS.11 PlayerDebugMode 1 defaults write com.adobe.CSXS.10 PlayerDebugMode 1 defaults write com.adobe.CSXS.9 PlayerDebugMode 1
  2. 2

    Copy the Pillow folder

    Unzip the archive and put the Pillow folder into the extensions folder. In Finder: Go → Go to Folder… (⇧⌘G) and paste:

    ~/Library/Application Support/Adobe/CEP/extensions
  3. 3

    Restart After Effects

    Quit it completely (check Activity Monitor) and open it again.

  4. 4

    Open the panel

    Window → Extensions → Pillow.

  1. 1

    Turn on CEP debug mode

    Once. Double-click enable-debug\Enable-CEP-Debug-Windows.reg from the archive and confirm. Or in regedit, add the string value PlayerDebugMode = 1 under

    HKEY_CURRENT_USER\Software\Adobe\CSXS.11
  2. 2

    Copy the Pillow folder

    Unzip the archive. Press Win+R, paste the path, hit Enter — and drop the Pillow folder there.

    %APPDATA%\Adobe\CEP\extensions
  3. 3

    Restart After Effects

    Close it completely (check Task Manager) and open it again.

  4. 4

    Open the panel

    Window → Extensions → Pillow.

Updating from an older build? If there's a com.pillow.panel folder in the extensions folder, delete it — two copies of Pillow shouldn't sit side by side.

Panel not showing up? Check that debug mode is 1, the path ends with …/CEP/extensions/Pillow/ and manifest.xml sits in the CSXS folder. Then fully restart After Effects.
